📖 刊物内页排版工具 v3.5
就绪 · 上传 docx / zip 或点「📂 打开」存档开始质检：待检查

① 文档顺序 （拖拽调整） ▾

    上传后自动套用刊物模板并默认双栏；可拖拽调序、点 ✕ 删除、＋ 增加空白文档。若样式识别不准，改完点「重新套版」。

    ② 栏目设置 （先点左侧文档名选中）

    一级 / 二级 / 三级均为单选，可「＋」新增、「✕」删除；含 AASLD / EASL / APASL 的稿件自动归入「会议撷萃」。竖排标签每页都有、按栏目配不同底色，并按「单页左 / 双页右」左右镜像。

    ③ 目录 （正文排完后自动带页码，可微调） ▾

    目录按栏目分组、带点线页码；预览中点击可跳转。修改正文后点「重新提取」或改动会自动刷新页码。

      ① 线上分享链接

      把当前整刊排版压进链接，发给对方打开线上工具即可还原审阅（依赖网络；稿件含图片较多时链接会较长）。

      ② 自包含 HTML 文件（离线可看）

      把排版与全部图片打包成单个 HTML 文件，对方双击即可在本地打开审阅，不依赖网络。
