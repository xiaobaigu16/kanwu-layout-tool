    ① 一键发布公开链接

    点一下即得 https 链接，可直接发给他人在浏览器打开，原样保留纸张尺寸、字体与图片，不含编辑器界面。免费匿名托管，链接到期自动删除（适合临时分享）；需永久链接请改用下方「导出 HTML 文件」放到自己的网站。

    ② 导出 HTML 文件（长期存档）

    导出一个自包含网页文件（.html），双击即可在本地浏览器打开，或放到任意静态网站（如 GitHub Pages）得到永久网址。含全部页面图片，所见即 PDF 成品。
